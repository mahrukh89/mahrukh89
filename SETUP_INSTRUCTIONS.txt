# GitHub Profile README Image Fix

This package fixes the broken GitHub stats/language/activity images in README.md.

## Upload these files

Repository: `mahrukh89/mahrukh89`

1. Replace your current root `README.md` with the included `README.md`.
2. Create the folder:
   `.github/workflows/`
3. Upload:
   `.github/workflows/profile-summary-cards.yml`

You do NOT need to manually create the `profile-summary-card-output` SVG files.
The GitHub Action creates them automatically.

## After uploading

1. Open the repository on GitHub.
2. Click `Actions`.
3. Click `GitHub Profile Summary Cards`.
4. Click `Run workflow`.
5. Run it on your default branch.
6. Wait for the green check.
7. Go back to `Code`.
8. You should see:
   `profile-summary-card-output/github_dark/`
9. Open your profile:
   `https://github.com/mahrukh89`

## What gets fixed

The old external services:
- github-readme-stats
- github-readme-stats/top-langs
- github-readme-activity-graph

are replaced with generated SVG files stored inside your own repository.

The README now uses:
- `3-stats.svg` = GitHub statistics
- `1-repos-per-language.svg` = top repository languages
- `5-profile-details.svg` = contribution/activity profile details

## Important

Do NOT paste a GitHub Personal Access Token directly into the YAML.
The workflow uses GitHub's built-in `GITHUB_TOKEN`.

If the workflow fails with a token/permission error, first check:
Repository → Settings → Actions → General → Workflow permissions
and select:
`Read and write permissions`

Then run the workflow again.

The existing contribution snake is separate and can continue using its existing workflow.
