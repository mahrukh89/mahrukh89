# Profile Visual Interface

This repository powers the `mahrukh89` GitHub profile as an automated cybersecurity portfolio interface.

## Automation
- Contribution snake — GitHub Actions
- Portfolio Pulse — Python + GitHub API
- GitHub metrics — Python + GitHub API
- SOC Pulse — Python + public CISA KEV feed
- 3D contribution skyline — GitHub Actions

## Structure
- `.github/workflows/` automation
- `assets/` profile visual panels
- `metrics/` generated GitHub metrics
- `profile-3d-contrib/` generated contribution skyline
- `scripts/` Python generators

All portfolio claims are intentionally framed at student/junior level and automated metrics come from public data.
